## Bring real physics to Figma

Hand-keyframing a believable bounce is slow and rarely feels natural. Bounce
runs a real 2D physics simulation on your selected layers and turns the result
into editable keyframes that play natively in Figma.

- **Real simulation, not fake easing** - gravity, collisions, restitution, and friction
- **Live scrubbable preview** - tune the result before applying it
- **Native Figma keyframes** - keep editing the animation after it is baked
- **Code export** - copy CSS keyframes or export a ready-to-run HTML animation
- **Privacy by design** - your document content never leaves Figma

## Physics presets

| Preset | What it does |
| --- | --- |
| **Drop** | Falls and bounces on the floor, then settles. |
| **Pile Up** | Drops layers into a naturally colliding heap. |
| **Pinball** | Ricochets highly bouncy layers around a sealed box. |
| **Zero-G** | Creates a weightless drift with gentle turbulence. |
| **Float Up** | Lifts layers upward until they gather at the top. |
| **Tornado** | Swirls layers around a central vortex. |
| **Windblown** | Blows layers sideways like leaves in strong wind. |
| **Scatter** | Flings layers apart with energetic turbulence. |
| **Magnet** | Pulls layers toward the center to form a cluster. |

## Motion presets

| Preset | What it does |
| --- | --- |
| **Slide In** | Slides into place from any edge with optional bounce. |
| **Pop** | Scales into place with a responsive spring. |
| **Slide Out** | Slides away toward a selected edge. |
| **Zoom Out** | Shrinks down and moves away. |
| **Shake** | Wobbles along an axis and naturally settles. |
| **Pulse** | Quickly scales up and back to draw attention. |
| **Spin** | Rotates continuously or spins smoothly into place. |

## Simple workflow

1. Select one or more layers in Figma.
2. Choose a physics or motion preset.
3. Adjust the controls and scrub through the live preview.
4. Apply the result as native, editable Figma keyframes.
5. Refine the animation in Figma or export it for the web.
